# Centralphones

Web SaaS em Next.js, TypeScript e Tailwind CSS.

## Identidade visual

- Aparência inicial: modo claro
- Paleta inicial: Azul Royal (`#1769FF`)
- Paletas: Azul Royal, Roxo Premium, Verde Esmeralda e Laranja Energy
- Modos: claro e escuro
- Interface: Soft UI, botões flutuantes, gradientes e transições suaves
